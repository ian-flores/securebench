# securebench: Security Benchmark Datasets and Harnesses for Large Language Model Agents

Security-specific benchmark datasets and evaluation harnesses for Large
Language Model (LLM) agents in R. Measure prompt-injection resistance,
dangerous-code detection, and leakage of personally identifiable
information or secrets against labeled datasets; compute precision,
recall, and F1 metrics; generate confusion matrices; and run A/B
comparisons of guardrail configurations (for example, 'secureguard'
pipelines). Designed to complement the general-purpose 'vitals'
evaluation framework: guardrails export as 'vitals'-compatible scorers.
